# ADR-009: Independent Witness Model

**Document ID:** ADR-009  
**Title:** Independent Multi-Party Witness Network for Split-View Detection  
**Status:** APPROVED  
**Deciders:** Security Architect, Protocol Architect, Chief Architect  
**Date:** 2026-11-09  

---

## 1. Context and Problem Statement
An advanced attacker who compromises an origin CDN can execute a **split-view attack**: serving authentic, matching JavaScript to auditors, crawlers, or IP ranges associated with LUCENTRA, while simultaneously serving tampered, credential-stealing JavaScript to targeted retail users.

How can LUCENTRA protect users against targeted split-view tampering?

---

## 2. Decision Drivers
- Detection of geographically targeted or user-agent targeted malicious injections.
- Decentralized auditing without creating a single privileged crawler.
- Cryptographic non-repudiation of witness observations.

---

## 3. Considered Options
- **Option 1:** Single centralized LUCENTRA crawler.
- **Option 2:** Pure client telemetry reporting (Heavy privacy implications, leaks user browsing history).
- **Option 3:** Independent Witness Network (Distributed observer nodes running scheduled crawls from diverse networks and publishing signed observations).

---

## 4. Decision Outcome
**Chosen Option:** **Option 3: Independent Witness Network.**

Third-party node operators run autonomous witness daemons that crawl registered domains across diverse geographic regions, compute SHA-256 digests, and publish signed observation records. Discrepancies trigger automatic security alerts.

### Consequences
- **Positive:** Protects end-user privacy (users do not leak browsing history); detects localized or split-view attacks.
- **Negative:** Requires node operators to run daemons; network must handle consensus or conflict resolution.

---

## 5. Security Implications
Witness observations are cryptographically signed by the witness's registered secp256k1 key, preventing rogue observers from forging reports.
